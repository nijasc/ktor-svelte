# Module ktor-svelte

API reference for ktor-svelte. `ktor-svelte-server` is the Ktor plugin you install with `install(Svelte) { }`, and `ktor-svelte-gradle-plugin` is the `svelte { }` extension and the tasks it adds. Start with the [README](https://github.com/nijasc/ktor-svelte#readme) for setup and examples.
