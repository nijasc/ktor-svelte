# Upgrading to 0.11

0.11 renames the package of generated Kotlin and adds two files to production apps. Most apps only need to update imports.

## Generated Kotlin moved to io.github.nijasc.ktorsvelte

With frontend libraries on, ktor-svelte generates Kotlin such as `AppTheme`, `LucideIcon`, `Messages` and the `call.theme` and `call.messages` extensions. They now live in `io.github.nijasc.ktorsvelte` instead of `ktorsvelte`, so they no longer sit in a top-level package of their own. Update your imports:

```kotlin
import io.github.nijasc.ktorsvelte.AppTheme
import io.github.nijasc.ktorsvelte.LucideIcon
import io.github.nijasc.ktorsvelte.messages
```

In IntelliJ, replace `import ktorsvelte.` with `import io.github.nijasc.ktorsvelte.` across the project. To keep the old package instead, set it in `build.gradle.kts`:

```kotlin
svelte {
    libraries {
        generatedPackage = "ktorsvelte"
    }
}
```

## sitemap.xml and robots.txt

When your build has no `sitemap.xml` or `robots.txt`, ktor-svelte now serves generated ones: a sitemap of your prerendered pages, and a `robots.txt` that keeps crawlers out of your API. Set `siteUrl` to your public address, put your own files in `frontend/static/`, or turn both off with `sitemap = false`. See [Sitemap and robots.txt](../features/endpoints.md#sitemap-and-robots-txt).
