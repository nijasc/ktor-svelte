build.gradle.kts
import io.github.nijasc.ktor.svelte.gradle.DaisyTheme

svelte {
    libraries {
        daisyUi {
            themes(DaisyTheme.ShadcnLight, DaisyTheme.ShadcnDark)
            defaultTheme(DaisyTheme.ShadcnLight)
            prefersDark(DaisyTheme.ShadcnDark)
        }
        lucide()
        toasts()
    }
}
Application.kt
import io.github.nijasc.ktor.svelte.Svelte

install(Svelte) {
    generateTs = true
    apiDocs = true
}

Only settings that differ from the defaults are shown. Run ./gradlew svelteSync after changing libraries, and ./gradlew svelteConfig to review the result.

Every option is explained in Gradle settings and tasks and Ktor settings. For an existing project, ./gradlew svelteConfig shows what is set now and scores it the same way.
