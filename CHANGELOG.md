## Unreleased

### Added

- `ktor-svelte-server`: Ktor plugin that serves a SvelteKit `adapter-static` build from the classpath or a directory, with API prefixes, SPA fallback, ETags, cache headers and precompressed files.
- `ktor-svelte-server`: development mode that proxies frontend requests to Vite.
- `ktor-svelte-gradle-plugin`: installs and builds the frontend, and packages it into the JAR. Works with Bun, pnpm, npm and Yarn.
