# Code of Conduct

ktor-svelte is a small project with one maintainer and occasional contributors. This page says how we treat each other in issues, pull requests, discussions and any other project space.

## What we expect

- Be kind and patient. Many people here use Kotlin or Svelte for the first time.
- Assume good intent, and ask before you judge.
- Criticize code and ideas, never people.
- Accept that a feature request or pull request can be declined. Staying small is a goal of this project.
- Keep discussions on topic and in public, so others can learn from them.

## What we do not accept

- Harassment, insults, threats or personal attacks.
- Discriminating or demeaning comments about anyone's identity, background, experience or appearance.
- Sexual language or imagery.
- Publishing other people's private information.
- Repeatedly pushing a topic after the maintainer asked to stop.

## Reporting

Report a problem privately to the maintainer through the contact options on the [maintainer's GitHub profile](https://github.com/nijasc). Reports are kept confidential.

## What happens next

The maintainer reads every report and decides what to do. Depending on the case, that is a private note, a public warning, hiding or editing content, or a temporary or permanent ban from the project. Anyone who is asked to stop is expected to stop right away.

## Scope

This code of conduct applies in all project spaces, and in public spaces when someone represents the project.
